# Security Policy

## Supported versions

Only the latest release is supported with security updates.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose local files,
credentials, or Apple Music library data.

Use GitHub's private vulnerability reporting feature for this repository. Include:

- affected version
- macOS version
- reproduction steps
- potential impact
- any proposed mitigation

Never include Apple ID credentials, access tokens, or unredacted personal library data.
